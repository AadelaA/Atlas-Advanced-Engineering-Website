# Atlas Advanced Engineering – Website

The official website of **Atlas Advanced Engineering**, a student engineering organisation at the University of Southern Denmark in Sønderborg.

> **Status:** in development. Pages and content are still being added, so expect things to change.

## About

Atlas Advanced Engineering is a student-run organisation where students work on engineering projects outside of their regular coursework. This website presents who we are, what we are building, and how to get involved.

## Features

- [x] Home page
- [x] About / team page
- [x] Projects overview
- [x] Contact and how to join

## Built with

- HTML
- CSS
- JavaScript

## Running locally

1. Clone the repository:
```bash
   git clone https://github.com/<your-username>/atlas-website.git
   cd atlas-website
```
2. Open `index.html` in your browser.
